# 🌿 Health Awareness & AI Symptom Checker

> **My First B.Tech Project 🚀**

This project is a **Health Awareness & AI-based Symptom Checker Application** designed to help users understand their health conditions in a simple, interactive, and user-friendly way. It provides disease information, precautions, diet suggestions, daily goals, and nearby medical support based on user symptoms.

---

## 🧠 Project Idea

Many people ignore early symptoms due to lack of awareness.
This application acts as a **digital health companion** that:

* Analyzes user symptoms
* Predicts possible internal & external disorders
* Provides complete A–Z information about diseases
* Suggests diet, precautions, and daily habits
* Helps users find nearby hospitals & doctors
* Sets reminders for healthy routines

---

## ✨ Features

### 🔐 Authentication

* Login / Signup pages
* Attractive medical-theme UI
* Dark & Light mode support

### 🤖 AI Symptom Checker

* User enters symptoms
* System asks **Yes / No follow-up questions**
* Filters top **3 possible conditions**

### 📘 Disease Information Module

For each disease:

* Symptoms
* Precautions
* Temporary relief
* Long-term management
* Diet suggestions
* Daily goals

### ⏰ Daily Goals & Reminders

* Water intake reminder
* Medication alerts
* Exercise goals
* Sleep tracking

### 📍 Nearby Care

* Shows nearby hospitals
* Doctor details & contacts
* Emergency support
